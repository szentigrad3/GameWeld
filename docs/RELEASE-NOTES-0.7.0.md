# GameWeld 0.7.0 Stable

First stable release of the redesigned Trainer Library with Steam, Heroic and Lutris launcher integration. Includes publisher-page discovery, compatibility review, signed-catalog format, checksum-approved staging and rollback, and a read-only configuration preflight.

Field validation completed on an existing Linux game library for representative Steam-shortcut, Heroic and Lutris trainer handoffs. It does not assert compatibility with every game, trainer or launcher configuration.

Known limitation: no bundled provider-authenticated trainer feed or fully automatic third-party executable update service. See `THIRD-PARTY.md` for external components.
